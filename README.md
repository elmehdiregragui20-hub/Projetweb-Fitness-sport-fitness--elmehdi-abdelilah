# FitLife
Projet universitaire de programmation web — EFREI.

## Lancement
Ouvrir index.html dans un navigateur. Dans VS Code : ouvrir ce dossier, puis index.html. Live Server est facultatif. Aucun npm install, framework, serveur applicatif ou base de données.

## Structure
- index.html : accueil
- pages/ : programmes, conseils, IMC, à propos
- css/style.css : charte sombre/verte, Flexbox, Grid, responsive à 760 px
- js/script.js : menu mobile, filtres, calculateur IMC
- docs/maquette.html : maquette desktop et mobile reconstituée depuis le site le 17 novembre 2026 (pas une preuve de conception préalable)
- docs/REVISION.md : explications et préparation orale
- docs/VERIFICATION.md : vérifications et limites

## Avant la soutenance
Retrouver le dépôt GitHub original et sa véritable maquette, si elle existe. Reporter ces modifications dans le vrai dépôt puis effectuer des commits sous les identités réelles. Ne pas recréer un faux historique. Vérifier le dépôt Moodle et le lien GitHub remis.
Valider les cinq HTML avec le validateur W3C et le CSS avec son validateur. Une revue locale ne remplace pas cette validation.
